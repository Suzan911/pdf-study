# مُذاكِر PDF

موقع يقرأ ملفات PDF داخل المتصفح ويستخرج نصها، ثم يعرض:
- ملخصاً ونقاطاً رئيسية وأكثر الكلمات تكراراً
- خريطة ذهنية وتسلسلاً بصرياً للمحتوى
- اختبار اختيار من متعدد تفاعلياً مع الدرجة والتفسير

على GitHub Pages يعمل الموقع بالتحليل المحلي (ملخص استخلاصي وأسئلة إكمال فراغ).
التحليل الذكي بواسطة Claude متاح عند فتح الصفحة كـ Artifact في claude.ai.

لا يُرفع أي ملف إلى خادم؛ القراءة تتم بالكامل داخل المتصفح عبر PDF.js.
